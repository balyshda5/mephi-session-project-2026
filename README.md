## 2. Обновление системы и установка ПО

### 2.1. Обновление RED OS

Выполнено обновление установленных пакетов:

```bash
sudo dnf upgrade -y
```

### 2.2. Установка nginx и libcap-ng-utils

Установлены необходимые пакеты:

```bash
sudo dnf install -y nginx libcap-ng-utils
```

### 2.3. Установка tcpdump из RPM

RPM-пакет `tcpdump` был загружен в `/tmp` с помощью:

```bash
dnf download tcpdump
```

После загрузки пакет установлен командой:

```bash
sudo rpm -i /tmp/tcpdump-4.99.5-1.red80.x86_64.rpm
```

История операций DNF сохранена в:

```text
dnf.out
```

## 3. Работа с дополнительным диском

### 3.1. Создание раздела и файловой системы

На диске `/dev/sdb` создан один раздел:

```text
/dev/sdb1
```

На разделе создана файловая система `ext4` с меткой:

```text
MEPHI_WEB
```

### 3.2. Подключение файловой системы

Создан каталог:

```text
/mephi-web
```

Файловая система добавлена в `/etc/fstab` с использованием метки:

```text
LABEL=MEPHI_WEB /mephi-web ext4 defaults 0 2
```

После этого выполнено подключение:

```bash
sudo mount -a
```

Информация о каталоге `/mephi-web` сохранена в:

```text
stat.out
```

## 4. Настройка nginx

### 4.1. Запуск nginx

Сервис nginx запущен и добавлен в автозагрузку:

```bash
sudo systemctl enable --now nginx
```

Проверено, что сервис находится в состоянии `active`.

### 4.2. Журнал работы nginx

Журнал nginx за текущую загрузку системы сохранён командой:

```bash
journalctl -u nginx -b > ~/journalctl.out
```

Результат находится в:

```text
journalctl.out
```

## 5. Настройка доступа и безопасности

### 5.1. Разграничение доступа к проектному каталогу

Создан каталог:

```text
/data/mephi-2026
```

Создана группа разработчиков `developers` с GID `5500`.

Пользователям разработчиков назначены следующие UID:

| Пользователь | UID |
|---|---:|
| `user1` | 5501 |
| `user2` | 5502 |
| `user3` | 5503 |

Создана группа кураторов:

```text
curators
```

с GID `4444`.

В группу добавлены:

```text
curator1
curator2
```

Для каталога `/data/mephi-2026` настроены ACL:

- разработчики имеют права чтения, записи и выполнения;
- кураторы имеют права чтения и выполнения;
- остальные пользователи доступа не имеют;
- для новых файлов сохраняются права группы `developers`.

Проверка результата выполнена при работе от имени пользователей разных групп.

### 5.2. Возможность запуска tcpdump обычным пользователем

Для `/usr/sbin/tcpdump` настроены Linux capabilities:

```text
cap_net_admin,cap_net_raw=eip
```

Проверка выполнена командой:

```bash
getcap /usr/sbin/tcpdump
```

Результат сохранён в:

```text
getcap.out
```

SetUID для `tcpdump` не используется.

### 5.3. SELinux и публикация сайта

SELinux переведён в режим:

```text
Enforcing
```

Результат сохранён в:

```text
getenforce.out
```

Для `/mephi-web` настроен SELinux-контекст:

```text
httpd_sys_content_t
```

Каталог используется nginx в качестве корня сайта.
